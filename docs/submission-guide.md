# 프로젝트 제출 가이드

이 문서는 한화 AI 솔루션 챌린지 신입입문과정 제출 페이지를 공개 화면과 공개 API에서 확인해 정리한 안내입니다.

- 제출 페이지: <https://hanwha-newhire-ai-hub.popolong.workers.dev/>
- 확인 시각: 2026-09-07 (KST) · 제출 화면과 `/api/config` 재확인
- 확인 범위: 로그인 없이 열리는 제출 양식, `/api/config`, `/api/status`, 공개 과제 안내 PDF

## 제출 방식

현재 과정은 `team-part` 모드입니다. 팀과 파트를 선택한 뒤 팀 수정 PIN과 강사가 안내한 수업 제출코드를 입력해 제출합니다. 공개 설정 기준으로 8개 팀, 팀당 4개 파트, 전체 32개 파트 규모입니다. 관리자 인증이 필요한 개별 팀의 제출 원문·첨부파일은 공개되지 않으므로 이 저장소 문서에는 포함하지 않습니다.

## 필수 입력과 산출물

제출 화면의 프로젝트 프로필은 다음 순서로 문제와 결과를 기록하도록 구성되어 있습니다.

1. 프로젝트 주제 선택
2. 팀원 이름
3. 해결할 문제와 대상
4. 현재 상황과 불편
5. 활용 자료·데이터
6. 사용한 AI·자동화 도구
7. AI·자동화 흐름
8. 만든 과정
9. 완성한 결과
10. 효과와 활용 가치

막힌 점과 한계·배운 점·다음 적용 계획은 선택 입력이며, 추가 기록 편집기에 Markdown·표·이미지·HTML을 남길 수 있습니다.

최종 제출에는 다음 두 가지가 필수입니다.

- **과제 소개 영상:** 약 3분 내외. 문제와 필요성, 해결 과정, 결과물을 설명하고 실제 작동 장면을 반드시 포함합니다. 허용 형식은 MP4·WebM·MOV입니다.
- **만든 결과물:** 웹페이지는 누구나 열 수 있는 대표 링크를, 앱·문서·PPT·코드·ZIP 등은 실제 파일을 제출합니다.

화면 캡처·조사 자료·테스트 결과 같은 과정·근거 자료는 선택 첨부입니다. 공개 설정의 업로드 제한은 팀 전체 157,286,400바이트(150MiB), 파일당 99,614,720바이트(95MiB)이며, 페이지는 최대 10개 파일을 안내합니다. 실행 파일은 허용되지 않습니다.

## 제출용 파일

`main`의 `assets/`에 최종 제출 파일 3개를 모았습니다. 기존 안내 PDF와 폰트는 그대로 유지합니다.

| 제출 항목 | 파일 | 내용 |
| --- | --- | --- |
| 과제 소개 영상 | [video.mp4](../assets/video.mp4) | 3분 5초 Remotion 자막판 · AI 활용 사례 3가지·모바일 시연·기대효과 · 일러스트 5장 · 잔잔한 배경음·효과음 · TTS 없음 |
| 만든 결과물 | [ppt.html](../assets/ppt.html) | 이미지와 폰트를 포함한 14장 발표 HTML |
| 보고서·추가 자료 | [report.md](../assets/report.md) | 제출 화면의 필수·선택 항목과 상세 기록 전체 |

대표 링크는 로그인 없이 시연 가능한 <https://junyeong-nero.github.io/hanwha-ai-solution/src/?demo=1>입니다. 발표 HTML은 코드 붙여넣기 편집기의 스크립트 차단을 피하도록 파일로 첨부합니다.

영상은 [미리보기](../assets/video.html)에서 확인할 수 있습니다. [자막](../assets/video.srt), [대본과 근거](../video/대본.md), [Remotion 편집 원본](../video/README.md)도 함께 제공합니다. 시연은 샘플 데이터이며 실제 외부 AI·카카오 검색 호출 장면은 아닙니다. 이전 영상의 시간·장소 확정과 투표는 현재 기능에 맞춰 장소 후보 비교·의견 초안 전송으로 교체했습니다.

팀·파트·팀원 이름은 실제 제출자가 확인해야 합니다. 팀 수정 PIN과 수업 제출코드는 저장소에 넣지 않고 제출 화면에 입력합니다. 로컬 영상 제작 원본은 `outputs/`에 보존하며 Git에서는 제외합니다.
