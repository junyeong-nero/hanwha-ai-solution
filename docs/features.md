# MoonLight Hanwha 기능 명세

이 문서는 **MoonLight Hanwha** — 웹으로 구현하는 휴대폰 앱 형식의 사내 네트워킹 서비스 — 의 기능을 정의합니다. 서비스 배경·문제 정의·전체 방향은 [introduction.md](introduction.md)를 기준으로 합니다. 원문 자료는 [background.md](background.md)와 [overview.md](overview.md)에 보존되어 있습니다.

## 1. 서비스 개요

MoonLight Hanwha는 한화 그룹사 구성원이 계열사 안팎의 동료를 발견하고, AI가 추천한 모임에 참여하고, 익명 채팅에서 시작해 실제 만남까지 이어지는 경험을 하나의 앱 안에서 제공합니다.

- **폼팩터:** 웹 기반 모바일 앱 UI (휴대폰 화면 비율 기준)
- **핵심 은유:** 우주와 달빛 — 계열사는 행성, 커넥션은 빛, 만남은 베일을 벗기는 달빛
- **네비게이션:** 하단 탭 바 4개 — `홈` / `매칭` / `채팅` / `프로필`

각 탭의 역할은 다음과 같습니다.

| 탭 | 역할 |
| --- | --- |
| 홈 | 내 주변 동기·계열사 커넥션 현황을 태양계 그림으로 한눈에 파악 |
| 매칭 | AI가 내 프로필 설정을 기반으로 어울리는 모임을 리스트업 |
| 채팅 | 참가한 모임의 익명 채팅방, AI 장소 후보 추천, 만남 후 추억 공유 |
| 프로필 | 매칭의 재료가 되는 내 개인 설정값 관리 |

## 2. 홈 — 내 우주, 커넥션 현황판

홈 탭의 본질은 **나를 둘러싼 동기들과의 커넥션 현황을 한눈에 보고 파악하는 것**입니다.

### 2.1 태양계 뷰 (아는 사람이 늘수록 넓어지는 은하계)

- 행성과 바로 아래 계열사 목록에 같은 고정 번호를 표시하여 색에 의존하지 않고 계열사 이름·연결 수를 대조합니다. 아직 은하계에 합류하지 않은 계열사에는 번호를 표시하지 않습니다.
- 행성 또는 계열사 목록을 누르면 연결된 동료를 볼 수 있다는 안내를 표시합니다. 회전 중에도 번호는 똑바로 유지되고 모션 감소 설정에서는 함께 멈춥니다.

- 태양계 아래 **행성 번호 · 계열사** 목록은 아는 사람이 있는 계열사와 내 계열사를 먼저 보여 주고, 나머지는 `아직 우주 밖인 N곳 보기`로 접어 둡니다.
- 태양계 위에는 **다음 할 일** 카드가 있습니다 — ① 관심사·취미 설정 → ② 모임 참가 → ③ AI 장소 추천 기능 써보기. 아직인 첫 단계와 이동 버튼 하나만 보여 줍니다. 별도 단계 목록이나 홈 도움말 버튼은 두지 않습니다. 연결된 동료·참여 중인 모임·빛나는 행성 요약은 은하계 바로 위에 배치해 375×812 첫 화면에서 다음 행동과 함께 확인할 수 있습니다. 세 단계가 모두 끝나면 카드는 사라집니다. 발표용 백엔드에서 **처음 로그인한 사용자는 홈 대신 프로필 탭**에서 시작합니다(추천의 재료가 없으면 매칭이 비어 보이기 때문).

- 한화 그룹사 계열사를 태양계 시스템에 대입해, 각 계열사를 하나의 **행성**으로 표현합니다.
- 은하계에 떠 있는 것은 **아는 사람이 생긴 계열사와 내 계열사뿐**입니다. 처음에는 내 계열사와 이미 만난 동료의 계열사만 보이고, 새로운 계열사 동료와의 **만남이 성사될 때마다 그 계열사가 궤도에 합류**합니다. 행성을 눌러도 다른 계열사가 열리지는 않고 상세 시트만 뜹니다.
- 행성은 **궤도를 따라 계속 회전**합니다. 궤도마다 한 바퀴 도는 시간이 다르고(안쪽일수록 빠름), 시작 각도도 궤도·자리마다 어긋나 있어 같은 방향으로 줄지어 도는 느낌이 나지 않습니다.
- 자리는 안쪽 궤도부터 채우되 같은 궤도에서는 이미 찬 자리와 가장 먼 곳을 고르고, 세션 시드로 갈라 매번 다른 모양이 나옵니다. 한 번 정한 자리는 세션 내내 유지되고, 궤도 간격·자리 간격 모두 44px 터치 타겟 이상이라 회전 중 행성이 겹치지 않습니다.
- 특정 계열사 구성원과의 **만남이 성사되면 해당 계열사의 커넥션이 활성화**되고, 내 우주에서 그 행성이 **밝게 빛납니다**.
- 은하계 밖 계열사도 아래 **계열사 커넥션 목록**에는 모두 남아 있어(`미개척`), 내 네트워크가 어디까지 닿았는지 한눈에 드러납니다.
- 합류 연출(행성·궤도)과 궤도 회전은 `prefers-reduced-motion` 환경에서 멈추고, 행성은 시작 각도 그대로 정지한 상태로 보입니다.

### 2.2 내 행성 뷰 (내 계열사)

- 태양계에서 **내 행성(내 계열사)** 으로 들어가면 시점이 전환됩니다.
- 내 계열사 안에서 나와 연결된 사람들이 **위성처럼 나를 공전하는 그림**으로 연결을 가시화합니다.
- 연결된 사람이 늘어날수록 내 행성 주위의 위성이 늘어납니다.

## 3. 매칭 — AI 모임 리스트업

### 3.1 AI 추천

- **프로필 탭의 내 데이터**(관심사, 취미, 지역, 연령대, 원하는 모임 규모, 매칭 성향)를 전부 읽어 그에 알맞는 **모임 리스트**를 만들어 보여줍니다.
- 백엔드에서는 **규칙 기반 점수 엔진**(`rankByRules`)으로 추린 미참가 모임 상위 20개를 **OpenAI `gpt-5.4-mini`**가 의미적 관심사·선호에 따라 재정렬하고 이유를 만듭니다. 나머지 모임은 규칙 순서로 유지합니다. API 실패 시 전체 목록을 규칙 추천으로 대체합니다. 로컬 데모는 기존 지역·관계 방향 정렬을 사용합니다.
- 후보 선정·오류 시 대체에 쓰는 규칙 가중치 — 관심사·취미와 모임 태그의 겹침 **34%**, 깊은 유대/넓은 인맥 성향에 따른 아는 얼굴 비율 **22%**, 희망 인원과 예상 참여 인원의 거리 **16%**, 같은 성별 비율 **14%**(성향을 켠 경우), 같은 계열사 비율 **10%**(`계열사 안에서만` 성향), 남은 자리 **4%**. 적용되지 않는 항목은 빼고 나머지를 다시 정규화합니다.
- 선호 지역은 점수가 아니라 **하드 필터**입니다(3.5 참고). 이미 참가 중인 모임은 목록에서 빼지 않고 맨 뒤로만 밀립니다.
- 매칭 탭은 **모임 둘러보기**라는 제목으로 표시합니다. 추천 순서는 유지하되 카드에 AI 추천 이유·주의점·취향 일치 개수 배지를 노출하지 않습니다. 모임 정보와 참여 상태를 중심으로 간결하게 보여줍니다.
- 리스트의 각 모임에는 내가 한 번 이상 만났던 사람이 포함되어 있을 수도 있고, 모두 처음 만나는 사람일 수도 있습니다.

### 3.2 아는 사람 비율 표시 — 주황 띠

- 모임 안에 **아는 사람(한 번 이상 만난 사람)이 얼마나 포함되어 있는지**를 한화의 주황색 컬러를 이용한 **주황 띠**로 표현합니다.
- 띠가 길수록 아는 얼굴이 많은 모임, 짧거나 없으면 완전히 새로운 만남입니다. 프로필의 "깊은 유대 vs 넓은 인맥" 설정과 맞물려, 사용자가 원하는 성격의 모임을 직관적으로 고를 수 있게 합니다.

### 3.3 참가

- 원하는 모임에서 **`참가하기`** 를 누르면 해당 모임이 **내 채팅 탭에 채팅방으로 추가**됩니다. 참가한 모임의 카드는 버튼이 **`참가 중 · 채팅방 열기`** 로 바뀌어 그 방으로 바로 들어갈 수 있습니다.
- 카드의 제목 부분을 누르면 **모임 상세 시트**가 열립니다 — 태그(내 관심사와 겹치면 주황), AI 추천 이유, 멤버(익명 아바타·닉네임·관심사 태그, 아는 얼굴 표시)를 보고 참가를 결정합니다.
- 정원이 찬 모임은 카드에서 미리 **`정원 마감 · N/정원명`** 으로 비활성화됩니다.
- 참가할 수 있는 모임은 **아직 열려 있고 정원이 남은 모임**뿐입니다. 정원이 찼거나 만남이 끝난 모임은 추천 목록에서 빠지고, 서버도 참가를 거절합니다("정원이 찼거나 마감된 모임이에요").
- **참가 이전에 오간 대화는 보이지 않습니다.** 채팅방에는 내가 참가한 시점부터의 대화만 나옵니다 — 방에 들어가 지난 익명 대화를 통째로 읽는 일을 막기 위해서입니다.

### 3.4 모임 직접 만들기

- 만들기가 끝나면 **새 방의 채팅방이 바로 열립니다**. 매칭 목록에서는 내가 만든 모임이 항상 맨 위에 옵니다.

- AI 추천에 원하는 모임이 없으면 매칭 탭 오른쪽 아래 **`모임 만들기` 플로팅 버튼**으로 직접 엽니다. 목록과 빈 상태 모두 만들기 진입점은 이 버튼 하나로 유지합니다.
- 모임마다 **이름 · 이모지 · 지역 · 관심사/취미 태그(1개 이상) · 시간대 · 정원**을 정합니다. 지역과 태그 목록에는 프로필에서 직접 추가한 항목도 나옵니다.
- 만든 사람은 바로 참가되어 채팅방이 열리고, 카드에 **"내가 만든 모임"** 표시가 붙습니다.
- 만든 모임은 다른 사용자의 AI 추천 후보에도 포함되어, 관심사·지역이 맞는 동료에게 추천됩니다.
- **친구 초대(선택):** 만남 완료로 연결된 친구(실명이 보이는 사람)를 방 멤버로 바로 초대할 수 있습니다. 방장만, 연결된 사람만 초대할 수 있고 초대된 친구의 채팅 탭에 방이 바로 나타납니다. 초대도 정원을 넘길 수 없어, 남은 자리만큼만 들어갑니다.

## 4. 채팅 — 익명에서 실명으로, 대화에서 만남으로

### 4.1 채팅방 리스트

- 매칭 탭에서 참가한 모임들이 **카카오톡 채팅방 리스트처럼** 표시됩니다.
- 채팅방에 들어가면 해당 모임에 참가한 인원들끼리 채팅이 시작됩니다.
- 백엔드 모드에서도 방별 안 읽은 메시지 수와 하단 채팅 탭의 합계를 실시간으로 표시합니다. 참가 이후 받은 다른 사람의 메시지만 세며, 방에서 조회한 메시지까지 읽음 기록을 저장해 새로고침·재접속 시 복원합니다. 앱이 숨겨진 동안에는 읽음 처리하지 않습니다.
- 백엔드 모드에서는 참가·초대·탈퇴 시 익명 시스템 메시지로 알리고, 열린 방의 멤버 수·익명 인원·멤버 버튼 숫자를 실시간으로 갱신합니다. 시스템 메시지는 안 읽음 수에 포함하지 않으며, 메시지 수신·재연결·앱 복귀 때도 서버의 멤버 상태를 반영합니다.
- 채팅방·사진첩이 열려 있어도 하단 탭 바는 그대로 보이며, 다른 탭을 누르면 열린 화면이 닫히고 이동합니다.
- 채팅방 상단의 **👥 멤버 버튼**(또는 `＋` 메뉴의 `채팅방 멤버 보기`)을 누르면 멤버 목록이 열립니다. 각 멤버의 표시 이름(서로 만남 완료한 사람은 실명·계열사, 아니면 닉네임·익명), **만남 완료 여부**를 한눈에 볼 수 있습니다.

- 열어 두지 않은 방에 새 메시지가 오면 **채팅 탭 배지와 목록의 안 읽음 수**가 올라갑니다(서버 모드는 받은편지함 Realtime 채널, 로컬 데모는 시뮬레이션). 방을 열면 0으로 돌아갑니다.
- 채팅에는 **날짜 구분선**(오늘 · 어제 · N월 N일)이 들어가고, 메시지는 500자까지이며 400자부터 남은 글자 수가 보입니다.
- 내가 아직 아무 말도 하지 않은 방에는 입력창 위에 **첫 인사 추천 칩**이 떠 있고, 누르면 그대로 보내집니다.

### 4.2 익명 원칙

- 채팅은 **기본적으로 익명**입니다. 참가자는 닉네임으로 표시됩니다.
- 단, **내가 한 번 이상 실제로 만난 사람은 실명으로 표시**됩니다. 같은 방 안에서도 익명과 실명이 섞여 보일 수 있습니다.

### 4.3 AI 장소 추천 — 후보를 비교하고 대화로 이어가기

- 채팅방 상단 `AI 장소 추천` 또는 `＋ → AI 장소 추천`에서 **모든 현재 참여자**가 후보를 요청할 수 있습니다. 날짜 입력·시간표·의견 수집·투표·장소 선택 확정·약속 확정·캘린더 추가는 제공하지 않습니다.
- 추천은 채팅 안의 카드로 도착합니다. **후보별 이름·업종·주소·추천 이유**와 지도, 실제 장소 상세 링크를 보여줍니다. 추천 이유는 후보 카드 오른쪽 위 ⓘ 버튼을 누르면 팝오버로 표시하고, 다시 누르거나 바깥 영역·Escape로 닫습니다. 모바일은 한 열, 넓은 웹 화면은 두 열로 비교하며 터치·키보드로 조작할 수 있습니다.
- 후보 카드의 말풍선 아이콘(`이곳 어때요?`)은 입력창에 **편집 가능한 의견 초안**을 넣습니다. 사용자가 직접 보내야 채팅으로 공유되며, 작성 중인 메시지가 있으면 덮어쓰지 않습니다. 상세 보기는 새 창 열기 아이콘으로 표시하며, 두 아이콘에 접근성 이름과 44px 터치 영역을 제공합니다. 지도나 목록에서 후보를 눌러도 다른 멤버의 선택을 바꾸거나 장소를 확정하지 않습니다.
- 다시 추천받으면 내가 조회할 수 있는 직전 추천의 장소를 제외하고 새 후보를 찾으며, 이전 후보는 접어서 남깁니다. 검색 범위 안에 새 후보가 없으면 기존 카드를 유지하고 안내합니다. 그보다 오래된 추천 장소는 다시 나올 수 있습니다. 로컬 데모도 직전과 다른 가상 후보를 보여줍니다. 요청 중에도 채팅할 수 있으며 연타를 차단합니다. 요청 중 방 이동·탈퇴·로그아웃을 해도 다른 방이나 다음 사용자의 화면에 결과를 섞지 않습니다. 실패하면 기존 후보를 보존하고 다시 시도 버튼을 제공합니다.
- 홈의 세 번째 할 일은 **`AI 장소 추천 기능 써보기`**입니다. 버튼을 누르면 참가한 채팅방으로 이동하고, 후보를 실제로 받아보면 완료됩니다. 기존 연결·만남 완료 여부나 추천 실패만으로 완료하지 않습니다. 로컬 데모는 새로고침하면 초기화됩니다.

#### 대화 기반 후보와 추천 이유

- 인증된 현재 참여자 본인의 **참가 이후 최근 메시지 최대 30개, 메시지당 300자**를 시간순으로 사용합니다. 발신자 UUID는 `참가자N`으로 바꾸며 대화 원문은 AI 실행 로그에 남기지 않습니다. 추천 카드는 사용한 가장 오래된 대화 이전부터 참가했던 사람만 조회할 수 있어, 생성 도중 들어온 멤버에게도 이전 대화가 요약되어 새지 않습니다.
- **대화 의도 추출 → 카카오 실제 장소 검색 → 검증된 후보 추천** 순서입니다. 최근 음식·활동·지역 선호와 거절·취소 맥락이 모임 제목·태그보다 우선합니다. 예를 들어 러닝 모임에서 “닭발 먹자”고 이야기하면 닭발 식당을 찾습니다. 지역 언급이 없으면 모임 지역을 사용합니다.
- OpenAI `gpt-5.4-mini`는 검색 후보 중 2~5곳(검색 결과가 하나면 한 곳)을 고르고, 각 후보의 **대화 선호와 검색된 지역·업종이 어떻게 맞는지** 이유를 설명합니다. 검색으로 알 수 없는 영업시간·가격·예약·좌석·주차·조용함·이동시간은 추측하지 않도록 지시합니다. 주소·좌표·링크는 카카오 결과로 검증합니다.
- 의도 분석 8초·최종 추천 20초 제한이며 실패하면 검색 결과 기반 후보와 그 사실을 표시합니다. 검색 실패 시 가짜 장소나 빈 카드를 저장하지 않습니다. 실제 영업·예약 여부는 사용자가 장소 상세에서 확인합니다.
- DB의 `recommendation_only`와 제약·트리거가 새 후보의 시간표·투표·장소 선택·확정을 차단합니다. 기존 약속 데이터와 마이그레이션은 이력으로 보존하지만 현재 화면에서는 후보만 표시합니다.
- 로컬 데모는 네트워크·LLM 없이 가상 식당·카페·티룸으로 체험합니다. ‘닭발’ 문자열에 따른 예시 분기를 제공하며 **데모 예시**임을 표시합니다. 실제 주소나 지도 링크로 오해할 정보를 붙이지 않습니다.

### 4.3.1 AI 스몰토크 — 대화 맥락과 요즘 트렌드

- 채팅방 `＋ → AI 스몰토크`에서 원하는 주제(선택, 80자)를 적고 질문 3개를 추천받습니다. 최근 대화·주제·모임 관심사를 참고하고, 웹 검색 소식에 연결한 질문에는 추천 이유와 클릭 가능한 출처를 표시합니다.
- 추천은 **나에게만 보이며** DB·채팅에 저장하지 않습니다. `이 질문으로 대화하기`는 편집 가능한 초안만 넣습니다. 작성 중인 메시지를 덮어쓰거나 자동 전송하지 않습니다.
- 서버는 현재 참여자를 인증하고 참가 이후 최근 메시지 최대 30개(각 300자)를 익명화합니다. 웹 검색에는 고정 목록에서 고른 일반 문화·취미 주제와 현재 날짜만 전달합니다. 검색 도구가 없는 후속 AI 호출에서 대화와 검색 결과를 연결합니다. 검색은 최근 2주 소식과 게시 날짜를 요청하며, 최신성·내용 확인은 출처에서 할 수 있습니다.
- 요청 중에도 채팅할 수 있고 중복 요청을 차단합니다. 방 이동·탈퇴·로그아웃 후 결과가 다른 방이나 사용자에게 섞이지 않습니다. 검색/AI 실패는 `기본 질문 · 웹 검색 결과를 가져오지 못했어요`로 표시하며, 요청 자체가 실패하면 이전 추천을 보존합니다. 다시 추천받을 수 있습니다.
- 로컬 데모는 외부 요청 없이 예시 질문을 제공하고 `데모 예시 · 웹 검색 없음`을 표시합니다. 서버 예산은 기존 전역 AI 일일 한도를 공유하며, 사용자·모임의 스몰토크 한도는 장소 추천과 별도로 적용합니다.

### 4.4 만남 완료 — 베일 벗기기

- 실제로 만난 뒤 각자 채팅방 **`＋ → 만남 완료`** 를 누르고 확인합니다. 장소 추천을 쓰지 않아도 가능합니다. 만남 완료는 **개인별 체크인**입니다.
- 현재 멤버이며 **첫 만남 완료 이전부터 참가한 사람**만 완료할 수 있습니다. 첫 체크인 이후 들어온 멤버가 지난 만남의 실명을 여는 경로를 서버에서 막습니다. 같은 모임의 체크인을 행 잠금으로 직렬화합니다.
- 나와 상대가 **둘 다 완료했을 때** 그 상대의 **익명이 실명·계열사로 바뀝니다**. 아직 완료하지 않은 멤버는 계속 익명으로 보이므로, 같은 방이라도 **사람마다 보이는 실명이 다릅니다**.
- 채팅방 상단에 `만남 완료 N/M`이 표시되고, 멤버가 완료할 때마다 "OO 님이 만남을 완료했어요" 알림이 옵니다.
- 만남을 완료하면 해당 채팅방의 **사진첩**이 열려 모임 구성원들이 **추억을 공유하는 플랫폼**이 됩니다.
- 서로 완료한 쌍은 연결(커넥션)이 되어 홈 탭의 행성 활성화(2.1)와 위성 추가(2.2)에 반영됩니다.

- **멤버 시트**에는 익명 멤버라도 **관심사 태그**(최대 3개)가 보여 대화 소재가 됩니다. 실명·사번은 그대로 연결된 상대에게만 보입니다. 이미 연결된 멤버에게는 `다음 모임` 버튼이 있어 새 모임 만들기 시트에 바로 초대 목록으로 담깁니다.
- **모임 나가기:** `＋` 메뉴에서 만남 완료 전까지 나갈 수 있습니다. 나가면 채팅 기록이 사라지고 참여 상태도 해제됩니다(서버 `leave_meeting`). 만남을 완료한 모임은 연결의 근거라 나갈 수 없습니다.

### 4.5 만남 평가 — 매칭 학습용 데이터

- 만남 완료를 누르면 **별 0.5~5점(0.5 단위)** 과 한 줄 코멘트(선택)를 받는 평가 시트가 열립니다. 별의 왼쪽 반을 누르면 0.5점, 오른쪽 반을 누르면 1점입니다. 나중에 `＋` 메뉴의 `만남 평가하기`로 다시 열 수 있습니다.
- 별점은 다른 멤버에게 보이지 않으며, **매칭 정확도를 높이기 위한 AI 학습용 데이터**로만 쓰입니다.
- 저장 시 서버가 그 시점의 특성 스냅샷 — 모임 지역·태그·인원·시간대, 내 관심사·취미·성별·연령·성향, 아는 사람 수, 같은 성별 비율, AI 장소 추천의 출처(LLM/기본) — 을 함께 기록해 **"특성 → 별점" 학습 예시**가 쌓입니다(`ai_training_examples`). 실명·사번은 포함하지 않습니다. 학습 자체는 이후 단계입니다.

## 5. 프로필 — 매칭의 재료가 되는 내 설정

프로필 탭은 **설문조사가 아니라 설정**입니다. 모든 값은 언제든 바꿀 수 있는 개인 설정값이며, 매칭 탭의 AI 추천에 즉시 반영됩니다.

### 5.1 기본 프로필

- 프로필 사진
- 닉네임 (익명 채팅에서 사용)

### 5.2 개인 정보 설정

| 항목 | 필수 여부 |
| --- | --- |
| 계열사 | **필수** |
| 선호 지역 | **필수** |
| 나이 | **필수** |
| 성별 | 선택 |
| MBTI | 선택 |
| 관심사 | 선택 |
| 취미 | 선택 |
| 원하는 모임 규모 (소규모 2~3 · 적당히 4~6 · 넉넉히 7~10 중 선택) | 선택 |

선호 지역·관심사·취미는 기본 목록 외에 **`＋ 직접 추가`** 로 항목을 만들 수 있고, 직접 추가한 항목은 칩 옆의 **×** 로 삭제할 수 있습니다 (기본 항목은 삭제되지 않습니다).

### 5.3 매칭 성향 설정

- **같은 성별 우선** — 같은 성별 멤버가 많은 모임을 먼저 추천 (성별을 설정해야 적용)
- **계열사 범위** — 내 계열사 안에서 만나고 싶다 / 다른 계열사 사람들과도 만나고 싶다
- **관계 방향** — 만났던 사람과 또 만나 깊은 유대를 형성하고 싶다 / 넓고 새로운 인맥을 만들고 싶다

### 5.4 저장

- 하단 행동 바에 **`모임 둘러보기`**를 항상 표시합니다. 설정을 바꾸면 **`저장하고 둘러보기`**로 바뀌고, 프로필에 머물며 저장할 수 있는 보조 **`저장`** 버튼이 함께 표시됩니다. 저장을 눌러야 매칭 추천에 반영되며, 매칭 탭은 로컬·서버 모드 모두 **마지막으로 저장한 프로필**만 씁니다(요약 띠·취향 일치 배지·지역 필터 포함). 저장하지 않은 변경이 있으면 매칭 탭 요약 띠 오른쪽에 **`저장 안 됨 · 저장하기`** 가 보입니다.
- 초기 제공 모임은 **인재경영원 교육 후 저녁 산책** 하나이며, 신규 프로필의 기본 선호 지역은 **인재경영원**입니다. 기존 사용자가 저장한 지역과 직접 만든 모임은 유지합니다.
- **선호 지역은 복수 선택**이 가능하고 최소 한 곳은 선택해야 합니다. 기본 지역 목록에는 판교·여의도·장교·**인재경영원**·대전·창원·서울숲이 있습니다.
- 매칭 탭은 **선호 지역에 있는 모임만** 보여줍니다. 지역 밖 모임은 아무리 관심사가 맞아도 추천되지 않습니다.

### 5.5 크레딧

프로필 가장 아래의 작은 텍스트 링크 **크레딧**을 누르면 만든이(한화시스템 해양사업부 SW1팀 송준영)와 2026년 9월 한화 인재경영원 4팀 3파트(송준영, 이수민, 이정현, 윤민영, 정태홍, 조성민)를 바텀 시트로 표시합니다. 닫기 버튼·배경·Escape로 닫으며, 작성 중인 프로필 설정은 유지됩니다.

## 6. 핵심 사용자 흐름

> **프로필 설정 → 매칭 탭에서 AI 추천 모임 확인(주황 띠로 아는 사람 비율 확인) → 참가 → 채팅 탭에서 익명 대화 → [AI 장소 추천 → 후보·이유 비교 → 채팅으로 의견 나누기] → 실제 만남 성사 → 베일 벗기기(익명→실명, 사진첩 생성) → 홈 탭의 행성이 밝아지고 위성이 늘어남**

### 6.1 첫 설정 및 사용 가이드

- 프로필은 아바타·닉네임 → 선호 지역 → 관심사·취미 → 기본 정보·매칭 성향 순서로 바로 설정합니다. 큰 준비 체크리스트 대신 한 줄 안내를 표시하고, 저장 성공 또는 저장된 설정으로 모임 둘러보기 완료 후 이 기기의 계정별로 숨깁니다. 선택 항목을 모두 채울 필요는 없습니다.
- 프로필 상단 ‘도움말’ 버튼을 누르면 바텀 시트에서 4탭의 역할, 모임 참가, AI 장소 추천 기능 체험, 상호 만남 완료에 따른 실명 공개, 사진첩과 연결 확인 방법을 볼 수 있습니다. 탭·작성 중인 설정은 유지합니다. 닫기 버튼·배경·Escape로 닫으면 원래 버튼으로 포커스가 돌아옵니다.
- 선호 지역은 필수이며 추천 범위를 제한한다는 점, 관심사·취미는 선택 사항이며 추천 순서에 쓰인다는 점을 입력 옆에 안내합니다.
- 하단 ‘저장하고 둘러보기’는 변경 사항을 저장한 뒤 매칭으로 이동합니다. 변경이 없으면 현재 저장된 설정으로 이동하며, 저장 실패 시 프로필과 변경 내용을 유지합니다.

만남이 반복될수록 홈 탭의 우주가 밝아지는 것이 이 서비스의 핵심 보상 루프입니다.

## 7. UI 디자인 원칙

우주·달빛·궤도 컨셉은 유지하되, 정보 위계와 조작감은 상용 커뮤니티·매칭 앱(당근 · 블라인드 · 에브리타임 · 틴더)의 관례를 따릅니다.

- **한 화면 한 목적:** 탭마다 상단 바(제목 + 오른쪽 원형 아이콘 버튼)와 섹션 제목으로 위계를 잡고, 본문은 카드 단위로 묶습니다. 매칭 탭은 상단에 내 기준 요약 띠(닉네임 · 계열사 · 지역 · 인원)와 가로 스크롤 빠른 필터(전체 · 지역별 · 내가 만든 모임), 오른쪽 아래 `모임 만들기` 플로팅 버튼을 둡니다.
- **모임 카드(매칭):** 단색 이모지 타일 · 제목 · 아이콘 메타(지역 · 시간대 · 인원/정원) · 태그(내 관심사와 겹치면 주황) · 구분선 · 멤버 아바타 묶음 + 아는 얼굴 수 · 주황 띠(%) · 전폭 `참가하기` 버튼 순서. AI 이유 패널과 취향 일치 배지는 없으며, 참가 상태는 `참가 중 · 채팅방 열기` 버튼으로 표시합니다. 일반 참가 버튼은 중립색으로 두고 모임 만들기 플로팅 버튼과 아는 사람 비율에 주황을 사용합니다.
- **채팅:** 목록은 큰 이모지 타일 · 제목(인원) · 마지막 메시지 · 시간 · 읽지 않음 배지. 채팅방은 같은 사람의 연속 메시지를 묶어 아바타·이름을 생략하고 묶음 끝에만 시간을 붙입니다. 내 말풍선은 주황 그라데이션과 어두운 글자, 시스템 안내는 달빛색 캡슐, AI 장소 추천 카드는 후보별 이유·주소·지도·상세 링크와 의견 초안 버튼을 담습니다.
- **프로필:** 아바타·닉네임·계열사 배지를 담은 히어로 카드 → `선호 지역` · `관심사·취미` · `기본 정보` · `매칭 성향` 섹션. 화면 아래에는 모임 이동 버튼을 고정하고, 변경 사항이 있을 때만 보조 `저장` 버튼을 표시합니다. 도움말은 프로필 상단, 로그아웃은 프로필 하단에 한 번씩 둡니다.
- **공통:** 모든 터치 타겟 44px 이상, 입력 글자 16px 이상(iOS 확대 방지), 안전 영역 반영, 눌림 피드백(살짝 줄어듦), 바텀 시트(손잡이 + 제목 + 닫기 버튼), 상단 토스트, 로딩은 스켈레톤, 빈 상태는 아이콘 + 제목 + 설명 + 다음 행동 버튼. 색·반지름·그림자·모션은 `styles.css` 의 `:root` 토큰만 씁니다.
- **반응형:** 휴대폰(≤599px)은 화면 폭 전체를 쓰고 좌우 16px, 태블릿(600~1023px)은 24px, PC(≥1024px)는 최소 32px 여백으로 제목·목록·행동 영역의 경계를 맞춥니다. 모임 카드는 모바일 1열·태블릿 2열·PC 3열이며, 프로필은 600px부터 관련 설정을 2열로 묶습니다. PC는 96px 세로 탭 레일과 최대 1080px 본문, 채팅은 최대 880px 본문을 사용합니다.
- **간격과 강조:** [Google Material Design의 간격 지침](https://m3.material.io/foundations/layout/grids-spacing/spacing)을 참고해 관련 요소는 4·8·12·16px, 그룹 사이는 24·32px 토큰으로 정리합니다. [색상 역할 지침](https://m3.material.io/styles/color/roles)에 따라 주요 행동은 한화 주황 배경과 어두운 글자, 선택한 칩·설정은 달빛색 표면으로 구분합니다. 선택 칩은 체크 표시와 `aria-pressed`를 제공하며, 공통 버튼·칩·시트 닫기는 48px 터치 영역과 키보드 포커스를 제공합니다.

## 8. 탭 간 데이터 관계

- **프로필 → 매칭:** 프로필 설정값이 AI 모임 추천의 입력이 됩니다.
- **매칭 → 채팅:** `참가`한 모임이 채팅방으로 생성됩니다.
- **채팅 → 홈:** 만남 성사가 계열사 커넥션 활성화(행성 점등)와 위성 추가로 반영됩니다.
- **만남 이력 → 매칭·채팅:** "한 번 이상 만난 사람" 기록이 주황 띠 계산과 실명 표시의 기준이 됩니다.
