사용 가이드
  1. 프로필 · 추천 기준 저장

    계열사·나이와 선호 지역을 확인해요. 관심사·취미·성별·MBTI·모임 규모는 선택 사항이에요. 같은 성별 우선은 성별을 설정해야 적용돼요.

  2. 매칭 · 모임 참가

    저장한 선호 지역의 모임만 보여요. 주황 띠는 이미 만난 사람의 비율이에요. 마음에 드는 모임의 ‘참가하기’를 누르거나 ‘모임 만들기’로 직접 열어보세요.

  3. 채팅 · 닉네임으로 인사

    참가한 모임이 채팅 탭에 생겨요. 처음 만나는 동료에게는 닉네임과 아바타로 보여요. 참가한 시점부터의 대화를 볼 수 있어요.

  4. AI 장소 추천 기능 써보기

    참가한 채팅방에서 ‘AI 장소 추천’을 눌러요. 최근 대화에 맞는 장소 후보와 추천 이유, 주소를 비교하고 지도에서 위치를 살펴봐요. 최근 대화 일부가 익명 처리되어 외부 AI에 전송돼요.

    ‘이곳 어때요?’를 누르면 메시지 초안이 만들어져요. 함께 갈 곳과 시간은 채팅으로 자유롭게 이야기해요.

  5. 실제 만남 · 각자 만남 완료

    실제로 만난 뒤 채팅방 ＋ 메뉴의 ‘만남 완료’를 눌러요. 나와 상대가 둘 다 완료해야 서로의 실명·계열사가 공개돼요. 첫 만남 완료 이후 참가한 멤버는 이 만남의 완료를 누를 수 없어요.

  6. 홈 · 넓어진 연결 확인

    서로 완료한 동료가 연결되고 해당 계열사 행성이 빛나요. 만남 완료 후 사진첩에 추억을 남기고, 만남 평가도 할 수 있어요.

모임이 보이지 않나요? 프로필에서 선호 지역을 더 선택하고 저장해 보세요. 원하는 모임을 직접 만들어도 좋아요.

나와 연결된 동료들이 위성처럼 곁을 돌고 있어요.
