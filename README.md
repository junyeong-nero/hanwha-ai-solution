### 제출 페이지 및 기존 교재

- **과제 제출 페이지:** [한화 AI 솔루션 챌린지 제출 페이지](https://hanwha-newhire-ai-hub.popolong.workers.dev/)
- **수업 제출코드:** `hh`
- **기존 교재:** [AI 교재](https://kai-cli-fieldbook.pages.dev/)
- **교재 입장코드:** `ai-campus.kr`

### 제출 방법

1. 화면 상단에서 소속 **팀(1~8팀)** 과 **파트(1~4파트)** 를 선택합니다.
2. 팀·파트에서 함께 사용할 **팀 수정 PIN(숫자 4~8자리)** 을 정합니다. 최초 제출과 질문·답변, 이후 수정에 같은 PIN이 필요하므로 팀원끼리 공유하고 기억해 둡니다.
3. 프로젝트 주제를 선택하고 편집기에 **문제와 필요성 · 해결 과정 · 결과** 를 자유롭게 작성합니다. 텍스트뿐 아니라 이미지도 붙여넣을 수 있습니다.
4. 과제 소개 영상을 업로드합니다. 영상에는 문제와 필요성, 해결 방식, 결과물의 실제 작동 장면, 결과와 효과를 담습니다.
5. 만든 결과물은 파일로 업로드하거나 대표 링크를 첨부합니다.
   - 웹페이지를 만든 팀은 주소를 입력합니다.
   - 영상·이미지·문서는 선택하거나 화면에 끌어놓아 업로드할 수 있습니다.
   - 파일은 최대 10개, 팀·파트별 약 100MB(안정 업로드 95MB)까지 제출할 수 있습니다.
6. 수업 제출코드 `hh`를 입력한 뒤 **프로젝트 최종 제출**을 누릅니다.
7. 제출 후에는 **제출 후 수정하기**에서 팀·파트와 팀 수정 PIN으로 다시 불러올 수 있습니다. 수정할 때 수업 제출코드는 다시 입력하지 않아도 됩니다.
8. 진행 중 문의는 같은 팀·파트와 PIN으로 **질문·답변 열기**에 남기면 해당 화면에서 답변을 확인할 수 있습니다.
