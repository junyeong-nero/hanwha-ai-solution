# MoonLight Hanwha

한화 그룹사 구성원을 위한 사내 네트워킹 모바일 웹앱 프로토타입입니다.
AI가 프로필 설정에 맞는 소모임을 추천하고, 익명 채팅에서 시작한 관계가 실제 만남과 새로운 커넥션으로 이어지는 경험을 우주와 달빛의 은유로 표현합니다.

## 한눈에 보기

- **폼팩터:** 휴대폰 화면에 맞춘 다크 테마 웹앱
- **핵심 은유:** 계열사는 행성, 연결된 동료는 위성, 만남 성사는 행성의 점등
- **주요 흐름:** 프로필 설정 → AI 모임 추천 → 모임 참가 → 익명 채팅 → AI 약속 추천 → 만남 후 베일 벗기기
- **데모 주소:** [GitHub Pages에서 열기](https://junyeong-nero.github.io/hanwha-ai-solution/src/)

## 주요 기능

### 홈 — 나의 우주

- 계열사별 연결 현황을 행성으로 보여줍니다.
- 실제 만남이 성사된 계열사는 밝게 빛납니다.
- 내 계열사 행성에서는 연결된 동료를 위성처럼 확인할 수 있습니다.

### 매칭 — AI 모임 추천

- 프로필의 계열사, 선호 지역, 나이, 관심사, 취미, 모임 규모와 매칭 성향을 추천에 반영합니다.
- 모임 카드의 한화 주황색 띠로 이미 만난 사람이 포함된 비율을 보여줍니다.
- `참가`를 누르면 해당 모임의 익명 채팅방이 생성됩니다.

### 채팅 — 익명에서 만남으로

- 참가자들은 기본적으로 닉네임으로 대화합니다.
- 이미 만난 사람은 실명으로 표시되어 익명과 실명이 함께 보일 수 있습니다.
- `＋` 메뉴의 **AI 추천 약속 잡기**가 채팅 내용을 바탕으로 장소·시간·활동·맛집을 제안합니다.
- 만남 완료 데모를 실행하면 익명 참가자가 실명으로 전환되고 사진첩이 열립니다.

### 프로필 — 매칭 설정

- 프로필 사진과 익명 채팅용 닉네임을 관리합니다.
- 필수 설정: 계열사, 선호 지역, 나이
- 선택 설정: 성별, MBTI, 관심사, 취미, 원하는 모임 규모
- 성비 균형, 계열사 범위, 관계 방향을 바꾸면 매칭 정렬에 바로 반영됩니다.

## 핵심 데모 흐름

1. `매칭` 탭에서 모임을 선택하고 **참가**합니다.
2. `채팅` 탭에서 생성된 방을 열고 `＋` → **AI 추천 약속 잡기**를 선택합니다.
3. 추천 카드에서 **이 약속으로 확정**을 누릅니다.
4. 상단의 **만남 완료 (데모)**를 눌러 베일 벗기기를 실행합니다.
5. `홈` 탭에서 연결된 계열사 행성이 점등되고 동료 수가 늘어난 것을 확인합니다.
6. `프로필` 탭의 선호 지역이나 관계 방향을 바꾼 뒤 매칭 순서 변화를 확인합니다.

## 구현 방식

- `src/`는 마크업(`index.html`)·스타일(`styles.css`)·화면별 스크립트(`js/`)로 나뉘어 있고, 빌드 도구 없이 브라우저가 그대로 읽습니다. 스크립트는 ES 모듈이 아닌 일반 `<script>`라 전역 스코프를 공유하며 로드 순서(`config` → `app` → 화면별 → `backend` → `boot`)에 의존합니다.
- **로컬 데모 모드(기본):** `src/js/config.js` 상단 `CONFIG`가 비어 있으면 외부 라이브러리·네트워크 요청 없이 브라우저에서 바로 실행됩니다. 데모 데이터는 `COMPANIES`, `PEOPLE`, `MEETINGS`, `PLANS` 상수에, 사용자 상태는 전역 `S` 객체에만 저장되며 새로고침하면 초기화됩니다.
- **백엔드 모드:** `CONFIG`에 Supabase URL과 anon 키를 채우면 supabase-js(CDN)를 불러와 사번 기반 데모 로그인(계열사·사번·이름으로 어느 기기에서든 같은 프로필·채팅 복원)·실시간 채팅을 사용하고, Supabase Edge Function이 OpenRouter LLM을 호출해 모임 추천과 약속 제안을 만듭니다. 설계는 [백엔드 설계 문서](docs/superpowers/specs/2026-09-02-supabase-openrouter-backend-design.md), 배포 절차는 [deployment.md](docs/deployment.md)를 참고하세요.
- 백엔드 코드는 `supabase/` (마이그레이션·시드·Edge Functions)에 있고, 테스트는 Node.js 24 이상에서 `npm test`로 실행합니다. `npm test`가 지원 버전을 먼저 확인하고, 미달하면 원인을 안내합니다.

## 실행 방법

빌드가 필요 없습니다. 저장소를 내려받은 뒤 브라우저에서 [`src/index.html`](src/index.html)을 열면 됩니다.

모바일 화면 기준으로 설계되었으므로 브라우저 개발자 도구에서 약 375×812 뷰포트로 확인하는 것을 권장합니다.
