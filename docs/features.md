# MoonLight Hanwha 기능 명세

이 문서는 **MoonLight Hanwha** — 웹으로 구현하는 휴대폰 앱 형식의 사내 네트워킹 서비스 — 의 기능을 정의합니다. 서비스 배경·문제 정의·전체 방향은 [introduction.md](introduction.md)를 기준으로 합니다. 원문 자료는 [background.md](background.md)와 [overview.md](overview.md)에 보존되어 있습니다.

## 1. 서비스 개요

MoonLight Hanwha는 한화 그룹사 구성원이 계열사 안팎의 동료를 발견하고, AI가 추천한 모임에 참여하고, 익명 채팅에서 시작해 실제 만남까지 이어지는 경험을 하나의 앱 안에서 제공합니다.

- **폼팩터:** 웹 기반 모바일 앱 UI (휴대폰 화면 비율 기준)
- **핵심 은유:** 우주와 달빛 — 계열사는 행성, 커넥션은 빛, 만남은 베일을 벗기는 달빛
- **네비게이션:** 하단 탭 바 4개 — `홈` / `매칭` / `채팅` / `프로필`

각 탭의 역할은 다음과 같습니다.

| 탭 | 역할 |
| --- | --- |
| 홈 | 내 주변 동기·계열사 커넥션 현황을 태양계 그림으로 한눈에 파악 |
| 매칭 | AI가 내 프로필 설정을 기반으로 어울리는 모임을 리스트업 |
| 채팅 | 참가한 모임의 익명 채팅방, AI 약속 잡기, 만남 후 추억 공유 |
| 프로필 | 매칭의 재료가 되는 내 개인 설정값 관리 |

## 2. 홈 — 내 우주, 커넥션 현황판

홈 탭의 본질은 **나를 둘러싼 동기들과의 커넥션 현황을 한눈에 보고 파악하는 것**입니다.

### 2.1 태양계 뷰 (아는 사람이 늘수록 넓어지는 은하계)

- 태양계 위에는 **다음 할 일** 카드가 있습니다 — ① 관심사·취미 설정 → ② 모임 참가 → ③ 만남 완료. 끝난 단계는 체크되고, 아직인 첫 단계로 가는 버튼이 붙습니다. 세 단계가 모두 끝나면 카드는 사라집니다. 발표용 백엔드에서 **처음 로그인한 사용자는 홈 대신 프로필 탭**에서 시작합니다(추천의 재료가 없으면 매칭이 비어 보이기 때문).

- 한화 그룹사 계열사를 태양계 시스템에 대입해, 각 계열사를 하나의 **행성**으로 표현합니다.
- 은하계에 떠 있는 것은 **아는 사람이 생긴 계열사와 내 계열사뿐**입니다. 처음에는 내 계열사와 이미 만난 동료의 계열사만 보이고, 새로운 계열사 동료와의 **만남이 성사될 때마다 그 계열사가 궤도에 합류**합니다. 행성을 눌러도 다른 계열사가 열리지는 않고 상세 시트만 뜹니다.
- 행성은 **궤도를 따라 계속 회전**합니다. 궤도마다 한 바퀴 도는 시간이 다르고(안쪽일수록 빠름), 시작 각도도 궤도·자리마다 어긋나 있어 같은 방향으로 줄지어 도는 느낌이 나지 않습니다.
- 자리는 안쪽 궤도부터 채우되 같은 궤도에서는 이미 찬 자리와 가장 먼 곳을 고르고, 세션 시드로 갈라 매번 다른 모양이 나옵니다. 한 번 정한 자리는 세션 내내 유지되고, 궤도 간격·자리 간격 모두 44px 터치 타겟 이상이라 회전 중 행성이 겹치지 않습니다.
- 특정 계열사 구성원과의 **만남이 성사되면 해당 계열사의 커넥션이 활성화**되고, 내 우주에서 그 행성이 **밝게 빛납니다**.
- 은하계 밖 계열사도 아래 **계열사 커넥션 목록**에는 모두 남아 있어(`미개척`), 내 네트워크가 어디까지 닿았는지 한눈에 드러납니다.
- 합류 연출(행성·궤도)과 궤도 회전은 `prefers-reduced-motion` 환경에서 멈추고, 행성은 시작 각도 그대로 정지한 상태로 보입니다.

### 2.2 내 행성 뷰 (내 계열사)

- 태양계에서 **내 행성(내 계열사)** 으로 들어가면 시점이 전환됩니다.
- 내 계열사 안에서 나와 연결된 사람들이 **위성처럼 나를 공전하는 그림**으로 연결을 가시화합니다.
- 연결된 사람이 늘어날수록 내 행성 주위의 위성이 늘어납니다.

## 3. 매칭 — AI 모임 리스트업

### 3.1 AI 추천

- **프로필 탭의 내 데이터**(관심사, 취미, 지역, 연령대, 원하는 모임 규모, 매칭 성향)를 전부 읽어 그에 알맞는 **모임 리스트**를 만들어 보여줍니다.
- 순위는 **규칙 기반 점수 엔진**이 매깁니다(`_shared/recommendation.ts`의 `rankByRules`). 외부 LLM을 부르지 않으므로 **대기 없이 즉시** 나오고, 같은 프로필·같은 모임이면 **항상 같은 순서**가 나옵니다.
- 항목별 가중치 — 관심사·취미와 모임 태그의 겹침 **34%**, 깊은 유대/넓은 인맥 성향에 따른 아는 얼굴 비율 **22%**, 희망 인원과 예상 참여 인원의 거리 **16%**, 같은 성별 비율 **14%**(성향을 켠 경우), 같은 계열사 비율 **10%**(`계열사 안에서만` 성향), 남은 자리 **4%**. 적용되지 않는 항목은 빼고 나머지를 다시 정규화합니다.
- 선호 지역은 점수가 아니라 **하드 필터**입니다(3.5 참고). 이미 참가 중인 모임은 목록에서 빼지 않고 맨 뒤로만 밀립니다.
- 매칭 탭은 **모임 둘러보기**라는 제목으로 표시합니다. 추천 순서는 유지하되 카드에 AI 추천 이유·주의점·취향 일치 개수 배지를 노출하지 않습니다. 모임 정보와 참여 상태를 중심으로 간결하게 보여줍니다.
- 리스트의 각 모임에는 내가 한 번 이상 만났던 사람이 포함되어 있을 수도 있고, 모두 처음 만나는 사람일 수도 있습니다.

### 3.2 아는 사람 비율 표시 — 주황 띠

- 모임 안에 **아는 사람(한 번 이상 만난 사람)이 얼마나 포함되어 있는지**를 한화의 주황색 컬러를 이용한 **주황 띠**로 표현합니다.
- 띠가 길수록 아는 얼굴이 많은 모임, 짧거나 없으면 완전히 새로운 만남입니다. 프로필의 "깊은 유대 vs 넓은 인맥" 설정과 맞물려, 사용자가 원하는 성격의 모임을 직관적으로 고를 수 있게 합니다.

### 3.3 참가

- 원하는 모임에서 **`참가하기`** 를 누르면 해당 모임이 **내 채팅 탭에 채팅방으로 추가**됩니다. 참가한 모임의 카드는 버튼이 **`참가 중 · 채팅방 열기`** 로 바뀌어 그 방으로 바로 들어갈 수 있습니다.
- 참가할 수 있는 모임은 **아직 열려 있고 정원이 남은 모임**뿐입니다. 정원이 찼거나 만남이 끝난 모임은 추천 목록에서 빠지고, 서버도 참가를 거절합니다("정원이 찼거나 마감된 모임이에요").
- **참가 이전에 오간 대화는 보이지 않습니다.** 채팅방에는 내가 참가한 시점부터의 대화만 나옵니다 — 방에 들어가 지난 익명 대화를 통째로 읽는 일을 막기 위해서입니다.

### 3.4 모임 직접 만들기

- 만들기가 끝나면 **새 방의 채팅방이 바로 열립니다**. 매칭 목록에서는 내가 만든 모임이 항상 맨 위에 옵니다.

- AI 추천에 원하는 모임이 없으면 매칭 탭 상단의 **`＋ 새 모임 만들기`** 로 직접 엽니다.
- 모임마다 **이름 · 이모지 · 지역 · 관심사/취미 태그(1개 이상) · 시간대 · 정원**을 정합니다. 지역과 태그 목록에는 프로필에서 직접 추가한 항목도 나옵니다.
- 만든 사람은 바로 참가되어 채팅방이 열리고, 카드에 **"내가 만든 모임"** 표시가 붙습니다.
- 만든 모임은 다른 사용자의 AI 추천 후보에도 포함되어, 관심사·지역이 맞는 동료에게 추천됩니다.
- **친구 초대(선택):** 만남 완료로 연결된 친구(실명이 보이는 사람)를 방 멤버로 바로 초대할 수 있습니다. 방장만, 연결된 사람만 초대할 수 있고 초대된 친구의 채팅 탭에 방이 바로 나타납니다. 초대도 정원을 넘길 수 없어, 남은 자리만큼만 들어갑니다.

## 4. 채팅 — 익명에서 실명으로, 대화에서 만남으로

### 4.1 채팅방 리스트

- 매칭 탭에서 참가한 모임들이 **카카오톡 채팅방 리스트처럼** 표시됩니다.
- 채팅방에 들어가면 해당 모임에 참가한 인원들끼리 채팅이 시작됩니다.
- 채팅방·사진첩이 열려 있어도 하단 탭 바는 그대로 보이며, 다른 탭을 누르면 열린 화면이 닫히고 이동합니다.
- 채팅방 상단의 **👥 멤버 버튼**(또는 `＋` 메뉴의 `채팅방 멤버 보기`)을 누르면 멤버 목록이 열립니다. 각 멤버의 표시 이름(서로 만남 완료한 사람은 실명·계열사, 아니면 닉네임·익명), 약속 **확정 투표 여부**, **만남 완료 여부**를 한눈에 볼 수 있습니다.

### 4.2 익명 원칙

- 채팅은 **기본적으로 익명**입니다. 참가자는 닉네임으로 표시됩니다.
- 단, **내가 한 번 이상 실제로 만난 사람은 실명으로 표시**됩니다. 같은 방 안에서도 익명과 실명이 섞여 보일 수 있습니다.

### 4.3 AI 추천 약속 잡기

- 사람들이 이야기를 충분히 나눈 뒤, 입력창 옆 **`+` 메뉴의 `[AI 추천 약속 잡기]`** 를 누릅니다.
- AI가 먼저 **모임 지역과 관심사로 실제 장소를 검색**해 후보지를 리스트업하고(카카오 로컬 검색 우선, 없으면 OpenRouter 웹 검색), 그 후보 안에서 **그동안의 채팅 내용**에 맞춰 다음을 한 번에 추천합니다.
  - 만날 장소 (후보지 중 하나)
  - 만날 시간
  - 만나서 할 활동(액티비티)
  - 주변 맛집·카페
- **AI가 쓴 장소 이름을 그대로 확정하지 않습니다.** 서버가 LLM 응답을 검색 결과와 대조해, 검색에 없는 장소는 후보에서 빼고 남은 후보에는 **장소 ID·주소·좌표·분류·상세 링크**를 검색 값으로 채웁니다. 만남 장소도 남은 후보 중 하나로 맞춰집니다.
- 약속 카드에는 **후보지 지도와 목록**이 함께 있습니다.
  - 지도에 후보가 동시에 표시되고 지금 고른 후보가 강조됩니다. 목록 카드를 누르면 Marker가, Marker를 누르면 목록이 함께 바뀝니다(양방향).
  - `이 장소로 정하기` 를 누르면 그 후보가 이 약속의 만남 장소가 되고, 같은 방의 다른 멤버 화면에도 실시간으로 반영됩니다. 확정된 약속의 장소는 바뀌지 않습니다.
  - 같은 이름의 다른 장소가 함께 잡히면 `같은 이름 여러 곳` 배지와 주소로 구분합니다. 검색으로 확인하지 못한 후보에는 `검색 미확인` 배지가 붙습니다.
  - **검색 결과가 없으면** 대체 검색어를, **할당량 초과·키 문제·오류**는 각각의 이유를 카드 아래에 안내합니다. 어떤 경우에도 약속 카드 자체는 그대로 뜹니다.
  - 지도는 카카오맵 JavaScript 키(공개용, 도메인 제한)가 있을 때 실제 지도로, 없으면 좌표를 상대 위치로 환산한 placeholder로 그려집니다. 장소 검색용 REST 키는 서버(Edge Function) 전용입니다.
- **기다림 안내:** 무료 모델은 20~30초가 걸릴 수 있어 8초·20초에 안내 문구가 바뀌고, 제안이 오기 전에 다른 방이나 탭으로 옮겨도 도착하면 토스트로 알립니다. 매칭 추천도 같은 방식으로 8초·20초에 문구가 바뀝니다.
- **확정은 전원 투표입니다.** 카드의 `이 약속으로 확정`을 누르면 주황 바가 `N/M`으로 차오르고, 채팅방 인원 **모두가 누르면** 약속이 잡힙니다. 한 명이 눌렀다고 확정되지 않습니다.
- **약속 시간이 지나면 자동으로 확정됩니다.** 아무도(또는 일부만) 확정을 누르지 않은 채 약속 시각이 지나면 카드가 `시간 지나 자동 확정 🌕` 상태로 바뀌고 "약속 시간이 지나 자동으로 확정했어요 — 만나셨다면 만남 완료를 눌러 주세요" 안내가 방에 남습니다. 실제로는 모두가 버튼을 누르는 일이 드물어, 지나간 약속이 영원히 `미확정`으로 남고 만남 완료(4.4)로 넘어가지 못하는 문제를 막습니다.
  - AI는 사람이 읽는 시간 문구(`이번 주 목요일 19:30`)와 함께 기계가 읽는 약속 시각 `meet_at`(KST ISO 8601)을 만듭니다. LLM이 `meet_at`을 주지 않거나 값이 이상하면 시간 문구를 파싱해 채웁니다.
  - `평일 저녁`처럼 **날짜를 짚을 수 없는 문구**는 `meet_at`이 비고, 그런 카드는 자동 확정 대상이 아니라 기존대로 전원 투표로만 확정됩니다.
  - 확정 경로는 `vote`(전원 투표)와 `due`(시간 경과)로 구분해 기록되며, 안내 문구도 서로 다릅니다.
- 목표는 사람들이 굳이 지도를 켜고 검색하지 않아도 **이 앱 안에서 약속의 전 과정이 해결되는 생태계**입니다.

### 4.3.1 공유 의견 제출 · 방장 비교 및 확정

- 채팅방 `＋ → 모임 의견 조율`에서 방장이 기존 AI 약속의 장소 후보로 의견 수집을 시작합니다. 수집 시작 전에 제출 마감(최대 30일 이내)과 후보 시작일을 정합니다. 기본 시간표는 **시작일부터 7일간 매일 18:00~22:00, 30분 단위, 한국 시간**입니다. 더 넓은 날짜·시간대 편집과 드래그 입력은 일정 이슈 #33의 확장 범위입니다.
- 공유 URL의 `poll` 값은 무작위 UUID입니다. 링크를 알아도 **로그인과 수집 시작 당시의 모임 참여 자격**이 있어야 열 수 있으며, 로그인 후 원래 링크로 돌아옵니다. 방장 권한은 모임의 `created_by`로 서버가 확인합니다.
- 참여자는 독립 화면에서 장소 후보를 **Radio로 한 곳 선택**, 가능한 시간 칸을 복수 선택하고 기타 의견(1,000자 이내)을 적습니다. 시간 미선택은 `가능한 시간 없음`을 뜻합니다. 제출 전 요약에서 수정할 수 있고, 재접속하면 본인의 마지막 응답이 복원됩니다.
- 사용자당 응답은 한 개입니다. 마감 또는 확정 전에는 덮어써 수정하고, 이후에는 읽기만 가능합니다. 탈퇴자는 접근할 수 없고 기존 응답도 집계에서 빠집니다. 수집 시작 후 새로 참가하거나 재참가한 사람은 해당 링크에 응답할 수 없습니다.
- 방장 비교 화면은 후보별 득표, 응답 완료 인원, 미응답자 닉네임, 시간별 가능 인원, 기타 의견 원문을 함께 보여 줍니다. **전원 가능(교집합)은 미응답자를 포함한 전체 유효 참여자 기준**입니다. 최신 응답 버튼으로 결과를 다시 불러오고, 같은 제출 링크를 복사해 재공유합니다.
- 방장은 같은 화면에서 장소와 미래의 후보 시간 한 칸을 선택해 최종 확정합니다. 마감 이후에도 확정할 수 있습니다. 서버의 약속 행 잠금으로 중복 확정·제출 경합을 막으며, 확정 결과는 기존 Realtime 채널을 통해 채팅의 시스템 메시지와 약속 카드에 반영됩니다.
- **의견 수집을 시작한 카드에는 기존 전원 투표·시간 경과 자동 확정을 적용하지 않습니다.** 수집을 사용하지 않은 카드는 기존 동작을 유지합니다. 수집 중 후보는 고정되며, 최종 장소·시간은 방장 확정으로만 정합니다.
- 로컬 데모에서는 직접 만든 모임의 명시적인 데모 후보로 시연합니다. 의견과 해당 모임은 이 브라우저의 로컬 저장소에 저장되어 데모 링크 재접속이 가능합니다. 다른 기기와의 공유·권한 검증은 백엔드 모드에서 제공합니다. 나머지 로컬 데모 데이터는 기존처럼 새로고침 시 초기화됩니다.

### 4.4 만남 완료 — 베일 벗기기

- 약속이 잡힌 뒤 실제로 만나면 각자 채팅방 상단의 **`만남 완료`** 를 누릅니다. 만남 완료는 **개인별 체크인**입니다.
- 완료를 누를 수 있는 사람은 **그 약속이 확정되기 전부터 방에 있던 멤버**뿐입니다. 이미 약속이 잡힌 방에 뒤늦게 들어와 곧바로 완료를 눌러 남의 실명을 여는 경로를 막습니다(확정 전부터 있던 멤버가 아니면 "확정된 약속이 있어야 만남 완료를 누를 수 있어요" 안내가 뜹니다).
- 나와 상대가 **둘 다 완료했을 때** 그 상대의 **익명이 실명·계열사로 바뀝니다**. 아직 완료하지 않은 멤버는 계속 익명으로 보이므로, 같은 방이라도 **사람마다 보이는 실명이 다릅니다**.
- 채팅방 상단에 `만남 완료 N/M`이 표시되고, 멤버가 완료할 때마다 "OO 님이 만남을 완료했어요" 알림이 옵니다.
- 만남을 완료하면 해당 채팅방의 **사진첩**이 열려 모임 구성원들이 **추억을 공유하는 플랫폼**이 됩니다.
- 서로 완료한 쌍은 연결(커넥션)이 되어 홈 탭의 행성 활성화(2.1)와 위성 추가(2.2)에 반영됩니다.

### 4.5 만남 평가 — 매칭 학습용 데이터

- 만남 완료를 누르면 **별 0.5~5점(0.5 단위)** 과 한 줄 코멘트(선택)를 받는 평가 시트가 열립니다. 별의 왼쪽 반을 누르면 0.5점, 오른쪽 반을 누르면 1점입니다. 나중에 `＋` 메뉴의 `만남 평가하기`로 다시 열 수 있습니다.
- 별점은 다른 멤버에게 보이지 않으며, **매칭 정확도를 높이기 위한 AI 학습용 데이터**로만 쓰입니다.
- 저장 시 서버가 그 시점의 특성 스냅샷 — 모임 지역·태그·인원·시간대, 내 관심사·취미·성별·연령·성향, 아는 사람 수, 같은 성별 비율, AI 약속의 출처(LLM/기본) — 을 함께 기록해 **"특성 → 별점" 학습 예시**가 쌓입니다(`ai_training_examples`). 실명·사번은 포함하지 않습니다. 학습 자체는 이후 단계입니다.

## 5. 프로필 — 매칭의 재료가 되는 내 설정

프로필 탭은 **설문조사가 아니라 설정**입니다. 모든 값은 언제든 바꿀 수 있는 개인 설정값이며, 매칭 탭의 AI 추천에 즉시 반영됩니다.

### 5.1 기본 프로필

- 프로필 사진
- 닉네임 (익명 채팅에서 사용)

### 5.2 개인 정보 설정

| 항목 | 필수 여부 |
| --- | --- |
| 계열사 | **필수** |
| 선호 지역 | **필수** |
| 나이 | **필수** |
| 성별 | 선택 |
| MBTI | 선택 |
| 관심사 | 선택 |
| 취미 | 선택 |
| 원하는 모임 규모 (N명 이상 ~ M명 이하) | 선택 |

선호 지역·관심사·취미는 기본 목록 외에 **`＋ 직접 추가`** 로 항목을 만들 수 있고, 직접 추가한 항목은 칩 옆의 **×** 로 삭제할 수 있습니다 (기본 항목은 삭제되지 않습니다).

### 5.3 매칭 성향 설정

- **같은 성별 우선** — 같은 성별 멤버가 많은 모임을 먼저 추천 (성별을 설정해야 적용)
- **계열사 범위** — 내 계열사 안에서 만나고 싶다 / 다른 계열사 사람들과도 만나고 싶다
- **관계 방향** — 만났던 사람과 또 만나 깊은 유대를 형성하고 싶다 / 넓고 새로운 인맥을 만들고 싶다

### 5.4 저장

- 설정을 바꾸면 하단에 **`저장 · 변경 사항 있음`** 바가 떠 있습니다. 저장을 눌러야 매칭 추천에 반영되며, 매칭 탭은 로컬·서버 모드 모두 **마지막으로 저장한 프로필**만 씁니다(요약 띠·취향 일치 배지·지역 필터 포함). 저장하지 않은 변경이 있으면 매칭 탭 요약 띠 오른쪽에 **`저장 안 됨 · 저장하기`** 가 보입니다.
- **선호 지역은 복수 선택**이 가능하고 최소 한 곳은 선택해야 합니다. 기본 지역 목록에는 판교·여의도·장교·**인재경영원**·대전·창원·서울숲이 있습니다.
- 매칭 탭은 **선호 지역에 있는 모임만** 보여줍니다. 지역 밖 모임은 아무리 관심사가 맞아도 추천되지 않습니다.

## 6. 핵심 사용자 흐름

> **프로필 설정 → 매칭 탭에서 AI 추천 모임 확인(주황 띠로 아는 사람 비율 확인) → 참가 → 채팅 탭에서 익명 대화 → [AI 추천 약속 잡기] → 실제 만남 성사 → 베일 벗기기(익명→실명, 사진첩 생성) → 홈 탭의 행성이 밝아지고 위성이 늘어남**

만남이 반복될수록 홈 탭의 우주가 밝아지는 것이 이 서비스의 핵심 보상 루프입니다.

## 7. UI 디자인 원칙

우주·달빛·궤도 컨셉은 유지하되, 정보 위계와 조작감은 상용 커뮤니티·매칭 앱(당근 · 블라인드 · 에브리타임 · 틴더)의 관례를 따릅니다.

- **한 화면 한 목적:** 탭마다 상단 바(제목 + 오른쪽 원형 아이콘 버튼)와 섹션 제목으로 위계를 잡고, 본문은 카드 단위로 묶습니다. 매칭 탭은 상단에 내 기준 요약 띠(닉네임 · 계열사 · 지역 · 인원)와 가로 스크롤 빠른 필터(전체 · 지역별 · 내가 만든 모임), 오른쪽 아래 `모임 만들기` 플로팅 버튼을 둡니다.
- **모임 카드(매칭):** 단색 이모지 타일 · 제목 · 아이콘 메타(지역 · 시간대 · 인원/정원) · 태그(내 관심사와 겹치면 주황) · 구분선 · 멤버 아바타 묶음 + 아는 얼굴 수 · 주황 띠(%) · 전폭 `참가하기` 버튼 순서. AI 이유 패널과 취향 일치 배지는 없으며, 참가 상태는 `참가 중 · 채팅방 열기` 버튼으로 표시합니다. 일반 참가 버튼은 중립색으로 두고 모임 만들기 플로팅 버튼과 아는 사람 비율에 주황을 사용합니다.
- **채팅:** 목록은 큰 이모지 타일 · 제목(인원) · 마지막 메시지 · 시간 · 읽지 않음 배지. 채팅방은 같은 사람의 연속 메시지를 묶어 아바타·이름을 생략하고 묶음 끝에만 시간을 붙입니다. 내 말풍선은 주황 그라데이션, 시스템 안내는 달빛색 캡슐, AI 약속 카드는 지도·후보지·전원 확정 진행 바를 한 카드에 담습니다.
- **프로필:** 아바타·닉네임·계열사 배지를 담은 히어로 카드 → `기본 정보` · `나에 대해` · `매칭 성향` 섹션. 변경 사항이 있을 때만 화면 아래에 `저장 · 변경 사항 있음` 바가 떠 있습니다.
- **공통:** 모든 터치 타겟 44px 이상, 입력 글자 16px 이상(iOS 확대 방지), 안전 영역 반영, 눌림 피드백(살짝 줄어듦), 바텀 시트(손잡이 + 제목 + 닫기 버튼), 상단 토스트, 로딩은 스켈레톤, 빈 상태는 아이콘 + 제목 + 설명 + 다음 행동 버튼. 색·반지름·그림자·모션은 `styles.css` 의 `:root` 토큰만 씁니다.
- **반응형:** 휴대폰(≤599px) 기준으로 설계하고, 태블릿(600~1023px)은 카드 2열, PC(≥1024px)는 왼쪽 세로 탭 레일 + 카드 3열로 펼칩니다.

## 8. 탭 간 데이터 관계

- **프로필 → 매칭:** 프로필 설정값이 AI 모임 추천의 입력이 됩니다.
- **매칭 → 채팅:** `참가`한 모임이 채팅방으로 생성됩니다.
- **채팅 → 홈:** 만남 성사가 계열사 커넥션 활성화(행성 점등)와 위성 추가로 반영됩니다.
- **만남 이력 → 매칭·채팅:** "한 번 이상 만난 사람" 기록이 주황 띠 계산과 실명 표시의 기준이 됩니다.
