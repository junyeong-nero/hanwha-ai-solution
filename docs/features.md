# 달빛한화 기능 목록

이 문서는 [`src/index.html`](../src/index.html)에 구현된 디자인 MVP의 기능과 현재 동작 범위를 정리합니다. 이 MVP는 실제 사용자·서버가 연결된 서비스가 아니라, 한 명이 두 사용자의 화면을 함께 조작하며 핵심 경험을 확인하는 인터랙티브 프로토타입입니다.

## 1. MVP가 보여주는 핵심 경험

달빛한화의 핵심 흐름은 다음과 같습니다.

> **이번 달 4인 그룹 확인 → 모임 이유 선택 → 그룹 초대장 전송 → 멤버들의 수락 또는 시간 변경 제안 → 모임 확정 → 다음 그룹으로 연결**

## 2. 화면 구성

### 모임 제안자: 이정현 · 한화투자증권

- 이번 달 4인 그룹의 이름, 멤버, 계열사와 공통점 확인
- `매칭`, `내 프로필`, `현재 참여중인 그룹` 탭 제공
- 그룹이 함께할 이유 선택 및 초대장 작성
- 초대장 전송 후 그룹 멤버 응답 대기 상태 확인
- 멤버들의 수락·시간 변경 답장 확인

### 그룹 멤버: 정하람 · 한화솔루션 큐셀부문

- 이번 달 4인 그룹의 이름, 멤버, 계열사와 공통점 확인
- `매칭`, `내 프로필`, `현재 참여중인 그룹` 탭 제공
- 받은 그룹 초대장 확인
- 제안된 시간을 수락하거나 다른 시간 제안
- 그룹 일정 확정 후 모임 정보 확인

두 화면은 하나의 브라우저 안에 나란히 배치되어, 그룹 초대장이 이동하는 과정을 한 번에 보여줍니다. 화면 폭이 900px 이하가 되면 두 휴대폰이 세로로 배치됩니다.

## 3. 기능 상세

### 3.1 이번 달 그룹 카드

- `판교 퇴근 후 달빛 모임`이라는 그룹 이름과 4명의 멤버를 표시합니다.
- 멤버별 이름, 계열사와 모임 내 역할(제안자·그룹 멤버)을 표시합니다.
- 4명·3개 계열사·판교 근무 등 그룹 규모와 활동 범위를 표시합니다.
- 러닝·위스키·엑셀·자동화·판교 등 공통 취향과 생활권 태그를 보여줍니다.
- `겹치는 취향 4개`, `계열사 3곳`처럼 그룹 매칭 이유를 설명합니다.
- 서로 다른 계열사의 동료가 함께 만나는 새로운 관계라는 점을 강조합니다.
- 이번 달을 쉬는 버튼을 제공하며, 클릭하면 `다음 보름에 다시 만나요`로 바뀌고 비활성화됩니다.

### 3.2 모임 이유 선택

`일 얘기로`와 `일 얘기 말고` 두 가지 카테고리에서 카드를 고릅니다.

- 업무형 모임 이유
  - 계열사 제품 한 장씩 교환
  - 우리 회사는 이렇게 일해요
  - 엑셀 자동화 미니 클리닉
- 비업무형 모임 이유
  - 회사 앞 국밥 원정대
  - 퇴근 후 20분 러닝 크루
  - 각자 한 잔씩 바꿔 마시기

각 카드에는 모임 예상 시간과 그룹 활동 설명이 있습니다. 카드를 선택하면 선택 상태가 강조되고, 그룹 이름·이유·시간·장소가 담긴 `그룹 초대장` 미리보기가 생성됩니다.

### 3.3 그룹 초대장 전송

- 미리보기의 `모임 제안하기` 버튼으로 그룹 초대장을 전송합니다.
- 제안자 화면은 `그룹 멤버들이 초대장을 읽는 중` 상태로 바뀝니다.
- 화면 중앙의 혜성이 제안자에서 그룹 멤버 화면으로 이동합니다.
- 멤버 화면에 알림 배지와 토스트가 나타나고, `모임 초대장` 탭에서 내용을 열 수 있습니다.
- 같은 초대장을 중복으로 보내지 않도록 전송 후 버튼을 비활성화합니다.

### 3.4 그룹 초대장 수락과 시간 변경

그룹 멤버의 `모임 초대장` 탭에서 다음 응답을 선택할 수 있습니다.

- `모임에 참여할게요`: 제안된 시간을 그룹 일정으로 수락합니다.
- 다른 시간 버튼 3개: 9월 1일, 9월 3일, 9월 5일 중 하나를 선택해 시간 변경을 제안합니다.
- 별도의 거절 버튼은 없습니다. 응답하지 않으면 이번 달 모임이 지나간다는 원칙을 안내 문구로 보여줍니다.

시간을 변경하면 제안자에게 답장 토스트가 나타나고, 제안자가 `이 시간으로 확정`을 눌러 그룹 일정을 확정할 수 있습니다.

### 3.5 그룹 일정 확정

- 양쪽 화면의 달이 보름달로 바뀝니다.
- 선택한 모임 이유, 일정, 판교 장소, 4명의 멤버와 계열사를 표시합니다.
- 그룹 멤버들이 모두 참석을 확정했다는 상태를 보여줍니다.
- 모임 3일 전 알림 예정 문구를 표시합니다.
- `캘린더에 넣기`, `판교 갈 만한 곳 세 군데 받기` 버튼을 제공합니다.
- 그룹 모임 확정 후 `멤버 한 명과 1:1 대화 시작하기`를 보조 액션으로 제공합니다.

### 3.6 현재 참여중인 그룹 목록

`현재 참여중인 그룹` 탭에서 참여 중이거나 참여 예정인 단체 톡방을 한눈에 확인합니다.

- 그룹별 달 진행도(0~100%)를 작은 달 아이콘과 수치로 표시합니다.
- 그룹 이름, 멤버 수, 참여 계열사 수, 현재 상태를 표시합니다.
- 최근 활동 내용과 읽지 않은 메시지 수를 함께 보여줍니다.
- 달 진행도가 높은 그룹이 위로 오도록 자동 정렬합니다.
- 동률인 경우에는 데모 데이터에 정의된 목록 순서를 유지합니다.
- 그룹 카드를 누르면 해당 단체 톡방을 열었다는 안내 토스트가 나타납니다.
- 첫 번째 그룹에 초대장이 도착한 상태라면 카드를 눌러 초대장 응답 화면으로 이동합니다.

현재 달 진행도는 멤버 응답과 활동량을 표현하는 발표용 데모 지표이며, 실제 채팅 메시지나 서버 활동량과 연결되어 있지는 않습니다.

### 3.7 지난 달 기록

과거 그룹 모임 기록 데이터는 데모 콘텐츠로 준비되어 있으며, 현재 하단 기본 탭에서는 노출하지 않습니다. 하단 탭은 현재 참여 중인 그룹을 우선 보여주는 구조입니다.

- 모임 이름, 참여 인원·계열사, 월, 한 줄 후기를 표시합니다.
- `만났어요`와 `못 만났어요` 상태를 구분합니다.
- 한 번 함께한 멤버 조합은 다시 매칭되지 않는다는 규칙을 안내합니다.
- 네 번의 그룹 모임 기록과 함께 `달빛지기`까지 남은 횟수를 보여줍니다.
- 달빛지기가 된 구성원이 직접 러닝·스터디 같은 모임을 열 수 있다는 중장기 확장 아이디어를 설명합니다.

### 3.8 내 달(프로필과 매칭 규칙)

양쪽 사용자 모두 `내 달` 탭에서 프로필을 확인합니다.

- 계열사, 직급, 연차, 근무 지역 및 사원증 인증 완료 상태 표시
- 관심사, 퇴근 후 활동 지역, 업무 관심사 태그 제공
- 태그를 클릭해 선택 상태를 토글
- 다음 매칭 규칙을 고정 규칙으로 표시
  - 4인 그룹 매칭 우선
  - 사원끼리만 매칭
  - 같은 부서 제외
  - 한 번 만난 사람 제외
- `다른 계열사 우선` 규칙은 켜짐·꺼짐을 직접 전환할 수 있습니다.
- 1:1 대화는 그룹 모임 확정 후 선택할 수 있다는 안내를 표시합니다.

### 3.9 알림과 초기화

- 상대 화면에 초대장 도착 토스트를 표시합니다.
- 탭의 알림 배지로 새 초대장 또는 답장 도착을 표시합니다.
- 토스트를 클릭하면 해당 초대장 또는 답장 화면으로 이동합니다.
- `처음부터 다시 보기` 버튼을 누르면 페이지를 새로고침해 데모를 초기 상태로 되돌립니다.
- 별 80개와 달빛 애니메이션으로 서비스의 시각적 분위기를 구성합니다.
- 사용자의 모션 감소 설정(`prefers-reduced-motion`)을 지원합니다.

## 4. 핵심 흐름 QA 체크리스트

- [ ] 페이지를 열었을 때 보내는 쪽과 받는 쪽 휴대폰이 모두 보입니다.
- [ ] 보내는 쪽에서 `모임 이유` 탭을 열 수 있습니다.
- [ ] `일 얘기로`와 `일 얘기 말고`를 전환할 수 있습니다.
- [ ] 이유 카드 1개를 선택하면 그룹 초대장 미리보기가 생성됩니다.
- [ ] `모임 제안하기`를 누르면 제안자가 대기 상태로, 그룹 멤버 화면에 알림 배지·토스트가 나타납니다.
- [ ] 그룹 멤버의 `모임 초대장` 탭에서 초대장 내용을 확인할 수 있습니다.
- [ ] 제안된 시간을 수락하면 양쪽 화면이 그룹 일정 확정 상태로 바뀝니다.
- [ ] 다른 시간을 제안하면 보내는 쪽에 답장 알림이 도착합니다.
- [ ] 보내는 쪽에서 변경된 시간을 확정할 수 있습니다.
- [ ] 확정 후 양쪽 달이 보름달로 바뀌고 약속 정보가 표시됩니다.
- [ ] `내 프로필` 탭에서 프로필·매칭 규칙을 확인할 수 있습니다.
- [ ] `현재 참여중인 그룹` 탭에서 그룹 멤버·상태·일정을 확인할 수 있습니다.
- [ ] 그룹 목록에서 달 진행도가 높은 단체 톡방이 위에 표시됩니다.
- [ ] 그룹 카드의 최근 활동·읽지 않은 메시지 수·진행도를 확인할 수 있습니다.
- [ ] 그룹 일정 확정 후 1:1 대화 시작하기를 눌러 보조 요청 토스트를 확인할 수 있습니다.
- [ ] 프로필 태그와 `다른 계열사 우선` 설정을 토글할 수 있습니다.
- [ ] `처음부터 다시 보기`를 누르면 초기 상태로 돌아갑니다.
- [ ] 화면 폭을 줄였을 때 두 휴대폰이 세로로 배치됩니다.

## 5. 현재 데모에서 동작하지 않는 항목

다음 버튼과 문구는 실제 외부 서비스와 연결되지 않은 시각적·설명용 요소입니다.

- `캘린더에 넣기`
- `판교 갈 만한 곳 세 군데 받기`
- `다른 날 더 보기`
- 받는 쪽의 `그룹 이유 보기`
- 약속 3일 전 실제 푸시 알림
- 사원증 인증과 사용자 로그인
- 실제 설문 수집, AI 호출, 매칭 계산, 백엔드 저장
- 응답 없음에 따른 실제 모임 만료 처리
- `이번 달은 쉴게요` 선택 결과의 저장 및 다음 달 반영
- 과거 그룹 기록을 별도 하단 탭에서 탐색하는 기능

## 6. 구현 메모

- 화면은 단일 HTML 파일에 CSS와 JavaScript를 함께 포함합니다.
- 현재 데모 상태는 `S` 객체에 저장되며, 새로고침하면 초기화됩니다.
- 이유 카드 데이터는 `REASONS`, 지난 만남 데이터는 `PAST` 상수에 하드코딩되어 있습니다.
- 그룹 멤버와 모임 정보는 `GROUP`, `REASONS`, `PAST` 상수에 하드코딩되어 있습니다.
- 두 사용자 화면은 하나의 `S` 상태를 공유해 그룹 초대·응답·확정 과정을 시뮬레이션합니다.
- 그룹 모임 확정 후 1:1 대화 요청은 `directInvite` 상태와 토스트로 선택적 흐름만 시뮬레이션합니다.
- 실제 서비스 전환 시에는 프로필·설문·매칭 이력·초대장 상태를 API와 데이터베이스로 분리해야 합니다.
